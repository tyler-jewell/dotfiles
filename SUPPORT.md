# Support

- **Usage questions:** read the [README](README.md), [FAQ](docs/FAQ.md) and
  [ADOPTING](docs/ADOPTING.md), then open a GitHub Discussion or an issue if
  Discussions are not enabled.
- **Bugs and feature requests:** open an issue with the templates. Include
  `./bootstrap.sh --check --json` output (redact anything private) and your git
  version.
- **Security issues:** see [SECURITY.md](SECURITY.md). Never a public issue.
- This is a volunteer-maintained project; replies are best effort.
